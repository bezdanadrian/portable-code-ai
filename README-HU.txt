HORDOZHATO KODOLO AI - Windows 10/11 x64

Inditas: START.bat. Az elso betoltes USB-rol nehany perc lehet.
Internet, Python es rendszergazdai jogosultsag a hasznalathoz nem kell.
Vallalati futtatasi korlatozasok, regi CPU vagy hianyzo rendszerkomponensek
akadalyozhatjak az inditast; minden gepre nem garantalhato kompatibilitas.

Iskolai alapbeallitas: 3B modell, 8 GB RAM-os gepekhez.
7B csak kezi valasztassal, eleg szabad memoriaval.
Az inditasnal kezzel is valaszthatsz. Ha lassu vagy keves a RAM, valassz 3-at.
A modell CPU-n fut. A sebesseg a processzortol es memoriatol fugg.

PARANCSOK
/fajl D:\projektek\program.py  - UTF-8 szoveges fajl csatolasa (max. 32 KB)
Ezutan ird le, mit javitson vagy bovitsen. Tobb kisebb fajlt is csatolhatsz.
/tobbsor - tobb soros kerdes vagy kod; kulon sorban /vege kuldi el
/ujbeszelgetes - elozmenyek es csatolt fajlok torlese a memoriabol
/mentes - beszelgetes mentese a beszelgetesek mappaba
/kilepes - kilepes es a hatterben futo modell leallitasa

A valasz folyamatosan jelenik meg, a vegen lathato a valaszido.
A kontextus 8192 token: hosszu beszelgetesnel kezdj uj beszelgetest.
A kodot a program megmutatja, de nem irja felul es nem futtatja automatikusan.
Az iskolai C# alaputasitas a school-profile.txt fajlban szerkesztheto.
Forrasok, tananyagkor es sajat probafeladatok: TANANYAG.md.
A generalt kodot ellenorizd sajat forditoval/tesztekkel. Python, .NET SDK es
C fordito nincs a csomagban. Magyarul is kerdezhetsz.

A teljes mappa masolhato masik USB-re; a meghajto betuje valtozhat.
A START.bat csak az adott PowerShell-folyamatra allit ExecutionPolicy Bypass-t.
A helyi kiszolgalo csak 127.0.0.1-en figyel. Nincs felhos AI-hivas.
